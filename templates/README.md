# Shared document templates

This directory is the shared source for reusable document templates. Templates
are identified by document type and may be used by multiple skills or other
authoring tools. A template does not require a dedicated skill.

| Template                                                                | Purpose                                                                     |
| ----------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| [Installation and Handover Record](installation-and-handover-record.md) | Project requirements, implementation, verification and operational handover |
| [Product documentation](product-documentation.md)                       | Product documentation using the product documentation standard              |

Keep template identifiers and source paths stable. Distributed package copies
must identify this source and remain consistent with the selected source
revision. Project-specific documents replace placeholders and record their own
classification, verification and approval state; using a template does not grant
installation or publication approval.
