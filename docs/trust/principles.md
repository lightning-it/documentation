# Principles and accountability

**Policy — portfolio scope.** Humans remain accountable for architecture,
classification, review, approval, risk decisions, and production promotion.
The public [documentation principles](../documentation-governance/principles.md)
define the governing source. This statement does not prove execution in a
specific delivery.

**Documented process — documentation scope.** Consequential changes pass
reviewable source control and the published
[quality gates](../documentation-governance/quality-standard.md).

**Known limitation.** Public repositories and successful checks provide
traceability, not independent assurance of a customer environment.
