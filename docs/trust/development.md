# Development lifecycle

**Documented process — public documentation repository.** Changes are proposed
on a branch, reviewed through a pull request, validated by required checks, and
promoted from `develop` to `main`. See
[GitHub issue conventions](../contributing/github-issues.md) and
[pipeline governance](../documentation-governance/documentation-pipeline.md).

**Current implementation — docs.l-it.io repository at the revision displayed
in the site footer.** Repository rules and workflows implement this path.
Public source is supporting evidence; it does not establish that another
repository or customer delivery uses the same controls.

Exceptions remain owned by the Repository Maintainers and require explicit,
reviewable disposition.
