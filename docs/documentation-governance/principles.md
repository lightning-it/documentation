# Documentation governance principles

Technical delivery records must be accurate, reproducible, phase-aware,
customer-readable, secret-safe, and traceable to evidence. Planning, observed
state, technical verification, handover, and customer decisions are distinct.
An Installation and Handover Record (IHR) is maintained as one document from
readiness through acceptance rather than being replaced at each gate.

Customer-language prose may be localised. Machine lifecycle values, stable rule
IDs, commands, paths, variable names, API fields, product names, full commits,
digests, and checksums remain unchanged. Public examples contain no customer or
confidential values.
