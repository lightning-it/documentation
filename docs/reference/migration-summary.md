# Initial documentation migration summary

The initial legacy corpus contained 140 inventoried documentation items. This
public page records only that coarse total and the publication decision. It does
not identify protected filenames, source locations, classification counts,
customers, findings, or retention targets.

No legacy file was copied directly into this public corpus. Public concepts
were independently rewritten and sanitized; excluded source material remains
outside the public repository. Exact classifications and findings are retained
only in restricted migration evidence. The candidate pages and their automated
target checks do not constitute human semantic, security, technical, or
licensing approval.

## Transformation approach

The public initial corpus was written as product-neutral or product-positioned
concepts using only the approved portfolio hierarchy, verified public component
repositories, official public standards, and documentation-only examples.
Examples use `example.com` and RFC-reserved addresses. No private source history,
screenshots, diagrams, inventories, runbooks, contacts, customer data,
credentials, environment paths, findings, or evidence were migrated.

## Protected records

File-level classifications, category counts, checksums, exclusions, source
identities, private retention destinations, reviews, and deletion gates can
reveal protected information. They remain outside the public documentation
corpus under their approved classification and retention controls.

Source deletion is a separate gated action. This summary does not claim that a
private source was deleted, that private retention is complete, or that
production acceptance has occurred. It also does not claim that a draft target
has passed the human comparison needed for migration acceptance.

See the [publication boundary](../security/publication-boundary.md) for the
classification method.
