# Support

Use GitHub issues for public documentation defects and improvement proposals:

<https://github.com/lightning-it/documentation/issues>

Include the page URL, expected information, observed problem, and browser or
build version when relevant. Do not include customer data, private environment
details, credentials, or operational incident information.

Product and commercial enquiries begin at <https://l-it.io>. Customer-specific
services use their approved customer channels. The separate
<https://portal.l-it.io> service is not this documentation site's support
system.

Security concerns follow [SECURITY.md](./SECURITY.md), not public issues.
